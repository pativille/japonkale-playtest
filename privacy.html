Anonim kullanım istatistiği (isteğe bağlı)

İlk açılışta sorarız. TAMAM dersen şunlar gönderilir:

  • Rastgele bir kurulum kimliği (128 bit, cihazında üretilir; seni tanımlamaz, başka bir bilgiyle eşleştirilmez).
  • Oyun açılışı; maç başlangıcı ve bitişi: maç türü (çevrimdışı / özel oda / hızlı maç), mod, harita, karakter, bot zorluğu, maçın bitip bitmediği, sıra, süre.
  • Davet linki paylaşımı ve davet linkiyle açılış (5 karakterli oda kodu), hızlı maçta başka insan olup olmadığı.
  • Oyun sürümü, dil (TR/EN), oyunun Ana Ekran'dan mı tarayıcı sekmesinden mi açıldığı.

Toplanmayanlar: ad, e-posta, IP adresi, konum, cihaz parmak izi, serbest metin. Bizim sunucumuz IP adresini okumaz ve kaydetmez.

Neden: Oyunun eğlenceli olup olmadığını (insanlar geri dönüyor mu, maçlar bitiyor mu) ölçüp geliştirmek için. Reklam ya da satış için kullanılmaz, kimseyle paylaşılmaz.

Japon Kale · Privacy

Last updated: 27 November 2026

In short: The game needs no account and does not collect your name, email, phone number, location, contacts or photos. It sends anonymous usage stats only if you allow it. If you don't, nothing is sent and no stats ID is stored on your device.

Anonymous usage stats (optional)

We ask on first launch. If you tap OK, we send:

  • A random install ID (128-bit, generated on your device; it does not identify you and is not linked to any other data).
  • Game opens; match start and end: match type (offline / private room / quick match), mode, map, character, bot difficulty, whether the match finished, rank, duration.
  • Invite link shares and opens (5-character room code), and whether another human joined a quick match.
  • Game version, language (TR/EN), and whether the game was opened from the Home Screen or a browser tab.

Not collected: name, email, IP address, location, device fingerprint, free text. Our server does not read or store IP addresses.

Why: to measure whether the game is fun (do people come back, do matches finish) and improve it. Never used for ads or sold, never shared.

Where and how long: stored on Cloudflare (Workers + D1, Europe region) and deleted automatically after 90 days. Cloudflare sees your IP at the network level to deliver the request; we do not write it to the database.

Turning it off: Home → SETTINGS → Anonymous stats: OFF. The install ID and unsent events are deleted from your device right away and nothing is sent.

Stored on your device

jk_tel_consentYour stats answer (yes/no), so we don't ask again.
jk_iid, jk_tel_qOnly if you allowed stats: install ID and unsent events.
Game settingsSound on/off, and a 60-second room ticket to return to your seat if an online match disconnects.

Online matches

In online matches our game server (Google Cloud, Frankfurt) processes only the movement data needed to run the match; it is not kept after the match. There are no usernames or chat.

Contact

For questions or deletion requests: tuhutufe@gmail.com. Because your install ID is anonymous we cannot link data to you; the simplest way is to turn stats off in SETTINGS (old records are deleted automatically within 90 days).
